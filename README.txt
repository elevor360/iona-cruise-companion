ELEVOR360D IONA CRUISE COMPANION - VERSION 1

1. Upload all files from this ZIP (not the enclosing folder) to a GitHub Pages repository.
2. Enable Pages in repository Settings > Pages > Deploy from branch > main / root.
3. Open the HTTPS Pages link on a phone. Use Install App when supported, or browser Add to Home Screen.
4. Visit the app online once to cache files for offline use.
5. To manage advertising open advert-manager.html in a browser, import advert-settings.json, edit, download the new file and replace it in GitHub.
6. Upload any advertising image/video into the repository too. Enter its relative path (e.g. ads/promo.jpg) in the manager. Images take priority over video.
7. The guide includes a starter venue list; edit venues.json for verified additions and changes.
8. Personal information is stored in browser localStorage only. Backup in Settings before clearing storage or switching phones.

IMPORTANT LIMITATIONS: This is an unofficial independent guide. No cabin-to-deck mapping is included because that must be verified. Venue decks and current schedules are not verified. Drink counter is a manual calendar-day tracker, NOT the cruise line's 6am package reset or an onboard purchase feed. Confirm current package rules, venue information, safety procedures, and bookings with P&O Cruises.

Version 1 is a working starting point, not a finished official ship navigation system.

ELEVOR360D IONA CRUISE COMPANION — FINAL CUSTOMER RELEASE V22

INSTALL / UPDATE
1. Extract this ZIP and upload its contents to the ROOT of the existing GitHub Pages app repository.
2. If upgrading, make a backup from Settings BEFORE replacing files.
3. Do NOT overwrite your published customised information.json, advert-settings.json or JPG advertisement files. Example copies are included only so a fresh install works.
4. Open the public HTTPS GitHub Pages link online and refresh once. Existing installed apps may require closing and reopening to load the update.
5. On Android Chrome, use Install App when offered or Chrome's Add to Home Screen / Install app menu.

USING THE APP
- Save cabin/deck, cruise dates and passenger details in Ship & Cabin.
- Browse decks, venues and entertainment; mark favourites.
- Add activities in My Cruise; view and print the itinerary in My Day.
- Keep drinks, spending and packing records. Print / Save as PDF uses the device browser print dialog.
- Open Share App to show the supplied QR code or share/copy the public app link.
- Settings offers backup and restore. Personal data is stored locally on each device and does not automatically sync.
- Owner's advertising and information updates require an internet connection. Previously cached content can be read offline.
